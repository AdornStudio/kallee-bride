# Kallee Bride — сайт салона свадебных платьев

Салон **Kallee Bride**, Нови-Сад — эксклюзивный представитель бренда **Lana Grace Bridal**.
Сайт на сербском языке. Сделан на Astro: статические страницы, быстрая загрузка, бесплатный хостинг.

---

## 1. Как запустить сайт у себя на компьютере

Откройте Терминал и выполните:

```bash
cd "/Users/mak/kalee site/kalee-bride"
npm run dev
```

Затем откройте в браузере **http://localhost:4321**

Сайт обновляется сам при любом изменении файлов — перезапускать не нужно.
Чтобы остановить — нажмите `Ctrl + C` в Терминале.

## 2. Где менять содержание

Дизайн трогать не нужно. Всё содержимое живёт в двух файлах:

### `src/data/site.js` — данные салона
Телефон, email, адрес, часы работы, Instagram, слоган.
Меняете здесь один раз — обновляется на **всех** страницах сразу.

### `src/data/i18n.js` — все надписи сайта, оба языка
Заголовки, описания, подписи кнопок, тексты страниц — на сербском и английском.
Нашли фразу, поменяли — она обновится на всех страницах этого языка.

### `src/data/collections.js` — коллекции и платья
Названия коллекций, описания, фотографии платьев.
Тексты записаны парами: `{ sr: 'сербский', en: 'английский' }`.

**Как добавить фото платья:** каждое фото нужно в трёх размерах — обычный для
галереи, `@2x` для приближения и `@thumb` для ленты миниатюр внизу. Из одного
исходника они делаются так:

```bash
cd "/Users/mak/kalee site/kalee-bride/public/images/gowns/luminous-veil"
sips -Z 1600 -s formatOptions 72 ~/Desktop/фото.jpg --out olivia-6.jpg
sips -Z 3200 -s formatOptions 65 ~/Desktop/фото.jpg --out 'olivia-6@2x.jpg'
sips -Z  160 -s formatOptions 62 ~/Desktop/фото.jpg --out 'olivia-6@thumb.jpg'
```

Затем впишите **только обычный** путь в `collections.js` — остальные два сайт
находит сам по имени:

```js
images: ['/images/gowns/luminous-veil/olivia-6.jpg']
```

Пустые кавычки `''` показывают аккуратную заглушку того же размера — сайт выглядит
законченным даже без фотографий, и вёрстка не «прыгает», когда фото появятся.

**Как добавить новую коллекцию:** скопируйте любой блок между `{ }`, вставьте ниже,
поменяйте данные. Страница для неё создастся сама — больше ничего делать не нужно.

### Видео на главном экране

На первом экране крутятся короткие ролики платьев, сменяя друг друга.
Список задаётся в `src/components/pages/HomePage.astro`, строка `const heroFilms`.
Чтобы поменять порядок или состав — отредактируйте этот массив.

Рядом стоит `const heroPoster` — это **первый кадр первого ролика**. Он показывается
мгновенно, пока грузится видео, поэтому при смене порядка роликов кадр надо вырезать
заново, иначе картинка дёрнется в момент старта.

Как вырезать первый кадр (заодно видно, как сжимать видео для сайта):

```bash
cd "/Users/mak/kalee site/kalee-bride/public/videos"

# сжать исходник: 6 секунд начиная с 3-й, вертикальные 540×960
avconvert -s ~/Desktop/исходник.mp4 -p Preset960x540 \
  -o новый.mp4 --start 3 --duration 6 --replace

# первый кадр в качестве заставки
avconvert -s новый.mp4 -p PresetPassthrough -o /tmp/tiny.mov --duration 0.2 --replace
qlmanage -t -s 1600 -o /tmp /tmp/tiny.mov
sips -s format jpeg -s formatOptions 82 /tmp/tiny.mov.png \
  --out ../images/hero-poster.jpg
```

**Важно:** ролик с телефона весит сотни мегабайт, ставить его как есть нельзя.
После сжатия 6 секунд занимают около 4 МБ — это верхняя граница приличного.

**Кадрирование.** На телефоне экран вертикальный и фото помещается целиком.
На широком мониторе оно бы обрезалось в узкую полосу, поэтому там сделан разворот:
текст слева, фото справа. Точка кадрирования — `object-position: center 25%`
в том же файле. Меньше процент — видно больше верха (лицо), больше — больше юбки.

> `slug` — это адрес страницы: `pure-grace` → `/kolekcije/pure-grace`
> Только латиница в нижнем регистре и дефисы. Без пробелов и без đ/š/ć/č/ž.

## 3. ⚠️ Что нужно настроить (обязательно)

### 3.1. Email салона
В `src/data/site.js` поле `email` пока пустое. Пока оно пустое, адрес просто
не показывается на сайте — ничего не выглядит недоделанным.

### 3.2. Форма записи пока никуда не отправляет
Файл: `src/pages/zakazivanje.astro`, переменная `FORM_ENDPOINT` в самом верху.

Что сделать:
1. Зарегистрироваться на **https://formspree.io** (бесплатно, карта не нужна)
2. Создать новую форму, указать email салона
3. Скопировать адрес вида `https://formspree.io/f/xxxxxxxx`
4. Вставить его в кавычки: `const FORM_ENDPOINT = 'https://formspree.io/f/xxxxxxxx';`

Бесплатный тариф — **50 заявок в месяц**.

Пока адрес не вставлен, форма честно пишет невесте, что заявку сейчас отправить
нельзя, и предлагает позвонить. Она **не** показывает фальшивое «спасибо».

### 3.3. Отзывы на главной — вымышленные
В `src/components/pages/HomePage.astro`, массив `testimonials`, помечен `⚠️ TODO`.
Три цитаты написаны для показа вёрстки. **Это не настоящие невесты.**
Замените их реальными отзывами (с разрешения авторов) до публикации сайта.

### 3.4. Шестая коллекция
В `collections.js` последний блок — заглушка `sesta-kolekcija`.
Впишите настоящее название и описание.

### 3.5. Адрес сайта
В `astro.config.mjs` поле `site` пока `https://www.kalee-bride.rs`.
Замените на реальный домен — от этого зависят SEO-теги и превью в мессенджерах.

## 4. Как опубликовать сайт в интернете

Бесплатно, через **Netlify**:

1. Зарегистрируйтесь на https://netlify.com
2. Соберите сайт: `npm run build` — появится папка `dist/`
3. Перетащите папку `dist/` в окно Netlify

Сайт получит бесплатный адрес вида `имя.netlify.app`.

Свой домен (например `kalee-bride.rs`) стоит примерно **10–15 € в год** —
это единственная платная часть. Всё остальное бесплатно.

## 4.5. Два языка

Сайт двуязычный: **22 страницы** — 11 на сербском и 11 на английском.

| Сербский | Английский |
|---|---|
| `/` | `/en/` |
| `/kolekcije` | `/en/collections` |
| `/kolekcije/pure-grace` | `/en/collections/pure-grace` |
| `/o-nama` | `/en/about` |
| `/kontakt` | `/en/contact` |
| `/zakazivanje` | `/en/book-a-fitting` |

Кнопка **SR / EN** ведёт не на главную, а на **ту же самую страницу** на другом
языке. На телефоне она внутри меню — в узкой шапке нет места для логотипа,
переключателя и кнопки меню одновременно.

**Вёрстка одна на оба языка.** Дизайн страниц лежит в `src/components/pages/`,
а файлы в `src/pages/` — это тонкие обёртки, которые только указывают язык.
Поэтому правка дизайна автоматически применяется к обеим версиям, и они не
могут разъехаться.

**Для Google** проставлены теги `hreflang`: они сообщают, что сербская и
английская страницы — одно и то же на разных языках. Без них поисковик счёл бы
их дублями и понизил обе.

> ⚠️ Английские тексты я написал сам — это **тексты вашего бренда**, их стоит
> вычитать. Всё лежит в `src/data/i18n.js` в разделе `en`.

## 5. Структура проекта

```
kalee-bride/
├── src/
│   ├── data/
│   │   ├── site.js            ← ★ данные салона
│   │   └── collections.js     ← ★ коллекции и платья
│   ├── layouts/
│   │   └── Layout.astro       ← общий каркас: шапка, подвал, SEO
│   ├── components/
│   │   ├── Header.astro       ← шапка и мобильное меню
│   │   ├── Footer.astro       ← подвал
│   │   ├── StickyBookBar.astro← нижняя полоса на телефоне
│   │   ├── CollectionCard.astro
│   │   └── Figure.astro       ← фото или заглушка
│   ├── pages/
│   │   ├── index.astro              → /
│   │   ├── kolekcije/index.astro    → /kolekcije
│   │   ├── kolekcije/[slug].astro   → все 6 страниц коллекций
│   │   ├── o-nama.astro             → /o-nama
│   │   ├── kontakt.astro            → /kontakt
│   │   └── zakazivanje.astro        → /zakazivanje
│   └── styles/
│       └── global.css         ← цвета и шрифты (в одном месте)
└── public/
    └── images/                ← ★ сюда класть фотографии
```

`[slug].astro` — один шаблон, из которого автоматически создаются **все**
страницы коллекций. Добавите седьмую коллекцию в данные — появится седьмая страница.

## 6. Дизайн

| | |
|---|---|
| Шрифт заголовков | Cormorant Garamond |
| Шрифт текста | Jost |
| Фон | `#fdfbf7` молочный |
| Фон секций | `#f5efe5` песочный, `#f0e4d2` шампань |
| Текст заголовков | `#241f1b` |
| Текст | `#6b6259` |
| Акцент (линии) | `#b08a52` |
| Акцент (текст) | `#7a5c2e` |

Цвета заданы в `src/styles/global.css` в самом верху. Меняете там — меняется весь сайт.

**Два золотых цвета сделаны намеренно:** светлый `#b08a52` — только для линий,
он слишком светлый для текста и не прошёл бы проверку контраста. Тёмный `#7a5c2e` —
для текста, читается на всех трёх фонах.

Контраст всего текста проверен: минимум **4.61** при норме 4.5 (стандарт WCAG AA).
Если будете менять цвета — проверьте контраст заново, это легко сломать.

### Анимации

Скорости и кривые плавности заданы переменными там же, в `global.css`:

| Переменная | Значение | Для чего |
|---|---|---|
| `--dur-press` | 160 мс | отклик кнопки на нажатие |
| `--dur-hover` | 220 мс | смена цвета при наведении |
| `--dur-ui` | 260 мс | меню, мелкие изменения |
| `--dur-reveal` | 800 мс | появление блоков при прокрутке |
| `--ease-out` | `cubic-bezier(0.23, 1, 0.32, 1)` | появление, исчезновение, нажатие |
| `--ease-soft` | `cubic-bezier(0.22, 1, 0.36, 1)` | медленные появления |

Что где происходит:

- **Каскад появления** — `src/layouts/Layout.astro`. Соседние элементы появляются
  с задержкой 60 мс друг за другом, максимум 300 мс. Меняется в константах
  `STAGGER_MS` и `STAGGER_MAX`.
- **Вход первого экрана** — `src/components/pages/HomePage.astro`, `@keyframes hero-in`.
- **Приближение фото** — там же, `@keyframes hero-settle`, 24 секунды.
  Чтобы убрать — удалите блок `@media (prefers-reduced-motion: no-preference)`.
- **Переходы между страницами** — `<ClientRouter />` в `Layout.astro`.

> ⚠️ Из-за переходов между страницами навигация стала внутренней: браузер не
> перезагружает страницу целиком. Поэтому **любой новый скрипт нужно запускать
> через `astro:page-load`**, иначе после перехода он не сработает. Примеры —
> в `Header.astro`, `StickyBookBar.astro`, `zakazivanje.astro`.

Всё движение отключается системной настройкой «Уменьшить движение», но подсветка
ссылок и рамка фокуса при этом сохраняются — это подсказки, а не украшения.

## 7. Что учтено

- **Мобильные в первую очередь** — проверено от 360px до больших экранов
- **Доступность** — навигация с клавиатуры, alt-описания, ссылка «пропустить меню»,
  учитывается системная настройка «уменьшить движение»
- **SEO** — свой заголовок и описание на каждой странице, разметка LocalBusiness/BridalShop
  для Google Maps, превью для мессенджеров, адреса страниц на сербском
- **Скорость** — статические страницы, минимум JavaScript, отложенная загрузка фото
- **Защита от спама** — скрытое поле-ловушка в форме записи
